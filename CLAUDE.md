# Zapvu — landing page

Landing page do **Zapvu**, uma API de WhatsApp não oficial do chefe do Guilherme, no estilo da Z-API: a pessoa cria uma instância, pega o token, escaneia o QR code e conecta o WhatsApp.

- O estudo das concorrentes (Z-API, W-API, Whapi, Ultramsg) e a estrutura proposta estão em `docs/estudo-concorrentes.md`. Leia antes de mexer no layout ou nos textos.
- As skills de front-end ficam em `.claude/skills`. Antes de criar ou mexer em tela, use `sem-cara-de-ia` e `design-taste-frontend` (ou `hallmark`). Para os textos, use `humanizer` ou `avoid-ai-writing`. Para movimento, use `animate`, `choreograph` e `review-animations`.
- Antes de mostrar qualquer tela, tire um print e passe pelo agente `diretor-de-arte`.
- Nunca use o logo do WhatsApp nem as cores dele como marca, e ponha no rodapé o aviso de não afiliação à Meta.
- Número e depoimento só se forem reais.
- Token, senha e chave de API nunca vão para o repositório.
