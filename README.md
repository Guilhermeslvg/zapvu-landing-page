# Zapvu — landing page

Site de apresentação do Zapvu, uma API de WhatsApp: crie uma instância, pegue o token, escaneie o QR code e mande mensagem pelo seu sistema.

- `docs/estudo-concorrentes.md`: estudo das concorrentes e a estrutura proposta
- `.claude/`: skills e agentes de front-end usados no projeto

## Como abrir

Sem build. Abra `index.html` no navegador, ou rode `npm install` e `npm run serve` (servidor estático local).

## Como tirar prints

`npm install` (uma vez) e `npm run shots`. Salva em `.shots/` (`desktop.png`, `mobile.png`, `hero-desktop.png`, e um por seção) e imprime erros de console e se há rolagem horizontal.

## Marca

Logos oficiais em `assets/brand/` (lima `#D5FF26`, oliva `#1E2104`). `zapvu-logo-horizontal-negativo.png` é o mesmo logo recolorido (letras claras) para fundo oliva, gerado por recolor do PNG oficial. Pendência: pedir ao chefe o logo em SVG e a versão negativa oficial.
